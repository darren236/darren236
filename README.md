# Hi, I'm Darren Tan

## NVIDIA work

During my time at NVIDIA, I created and maintained the public [NVAITC APS Project Demos](https://github.com/NVIDIA/nvaitc-aps-project-demos) collection using my former work account, [@dhui-nvidia](https://github.com/dhui-nvidia). The repository brings together reusable NVIDIA AI demos and workshop material for research, education, and industry collaboration.

Highlights include:

- Developing the [NIM Build, Tune & Deploy workshop](https://github.com/NVIDIA/nvaitc-aps-project-demos/tree/main/workshops/NIM-build-tune-deploy), covering NIM APIs, local GPU deployment, LoRA fine-tuning with NeMo, and adapter deployment with NIM.
- Building and maintaining repository structure, contribution workflows, licensing, documentation, and project curation.
- Contributing to applied AI projects spanning protein design, RAG, agentic systems, and model deployment.
- First-authoring [PRO-GO: Reference-Guided Protein Sequence Generation Using Gene Ontology Terms](https://doi.org/10.1109/ACCESS.2025.3646961), published in IEEE Access.

These are past-employer contributions and do not imply a current affiliation with NVIDIA.
